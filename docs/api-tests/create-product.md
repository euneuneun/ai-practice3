# 상품 등록 예외 테스트
- 요청: `POST /api/products`

| 번호 | 상황 | 기대 status |
|---|---|---|
| E1 | 필수 값(name) 누락 | 400 |
| E2 | 가격 또는 재고가 허용 범위 밖 | 400 |

## E1. 필수 값(name) 누락
준비: 없음

요청
```json
{
  "price": 25000,
  "stock": 100
}
```

응답 `400`
```json
{
  "status": 400,
  "message": "요청 값이 올바르지 않습니다."
}
```

## E2. 가격 또는 재고가 허용 범위 밖
준비: 없음

요청
```json
{
  "name": "무선 마우스",
  "price": -1,
  "stock": 100
}
```

응답 `400`
```json
{
  "status": 400,
  "message": "가격 또는 재고가 올바르지 않습니다."
}
```
